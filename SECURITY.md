# Security Policy

## Supported Versions

We release security fixes for the most recent minor version of the
`terraform-provider-azion`. Please make sure you are running the latest
release before reporting an issue:
https://github.com/aziontech/terraform-provider-azion/releases/latest


## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via GitHub Security Advisories:
https://github.com/aziontech/terraform-provider-azion/security/advisories/new

1. Go to the [**Security**](https://github.com/aziontech/terraform-provider-azion/security)
   tab of this repository
2. Click **Report a vulnerability**
3. Fill out the vulnerability report form

If you are unable to use GitHub Security Advisories, email us at
security@azion.com.

Please include as much detail as possible:

- A description of the vulnerability and its impact.
- Steps to reproduce (proof of concept, affected version, environment).
- Any suggested remediation, if known.
